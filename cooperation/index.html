常见问题

花城惠民·邻和花城惠民·伴有什么区别？

两条产品线对应两种街角生意。「邻」整合报刊阅读与便利零售业态，设双形态：便利店态适配广州一刻钟便民生活圈，服务街坊高频刚需；闪购态依托夜经济，面向青年、游客打卡引流。「伴」整合报刊阅读与预包装餐品模式，切中广州庞大的白领和通勤人群，兼顾“食在广州”的效率与卫生安全、拉高客单价。

A-1 / A-2 / B-1 / B-2 四种形态怎么选？

按“卖什么”选系列，按“放哪里”选进深：邻线 A-1（2.0 米进深标准型）与 A-2（1.8 米进深紧凑型），伴线 B-1（2.0 米标准型）与 B-2（1.8 米紧凑型）。设计适配上，2.0 米标准型适合主街口、社区中心与商圈街区，1.8 米紧凑型适合窄街巷口与通勤动线；最终选型以实地勘察为准。可在产品中心查看四形态对比表。

亭体是什么规格？工艺水平如何？

以 A 系标准型为例：总宽 4500mm、总高 2750mm、进深 2.0 米（紧凑型 1.8 米）；正面保留广州报刊亭经典的上翻式售卖窗口（高 770mm）与可折叠服务操作台（高 200mm）；主体为 1.2mm 镀锌板户外氟碳喷漆，标配 P2 LED 显示屏与迷你发光立体字。完整参数见各形态详情页“规格参数”版块。

既有报刊亭网点如何参与转型升级？

本项目即广州报刊亭转型升级示范项目：以现代化设计激活既有报刊亭网点，保留上翻窗等经典交互与报刊阅读功能，让老网点带着城市阅读记忆继续服务街坊。网点参与改造的具体路径与条件，以双方洽谈为准。

一座亭可以承载哪些经营内容？

因形态而异：便利店零售（饮料、零食、应急日用）与报刊阅读是共同基础；A-1 背面配 24H 零售店（冷藏陈列），A-2 背面配 24H 换电柜；B 系经营预包装餐品零售；各形态均配备背面 P2 LED 显示屏、灯箱与发光字组成的街角媒体位。

从意向到落位的合作流程是怎样的？

四步走：①提交意向——填写本页表单；②点位/需求评估——实地勘察并给出选型建议（四形态对号入座）；③方案与协议——确定形态、业态组合与合作条款；④生产落位——工厂预制、街角安装、验收亮灯。评估与协议环节的具体标准与周期，以双方洽谈为准。

供电、报批等落地条件如何解决？

街角落位涉及供电接驳与属地报批，需结合具体点位实地评估；项目方在“点位/需求评估”环节提供勘察支持。各项要求以属地主管部门规定与双方洽谈为准。

预包装餐品的卫生安全怎么保障？

「伴」线采用预包装餐品模式：餐品在供应链端完成品控与封装，亭端即取即走——封签完好、保质期可视，这是策划方案对“食在广州”效率与卫生安全的兼顾。食品经营相关资质与监管要求，以国家及属地规定为准；具体经营安排以双方洽谈为准。

可以只合作广告媒体位吗？

可以。各形态亭体标配背面 P2 LED 显示屏、侧面民生海报灯箱、正面灯箱广告带与迷你发光立体字——白天卖商品，夜里是街角媒体。提交表单时在“合作类型”中选择「品牌广告」即可。

投入、分成、租期等商务条款如何确定？

本官网是品牌与信息展示窗口，不标注任何价格与合作条款；投入、分成、租期、加盟费用等商务事项，均以双方洽谈为准。欢迎提交表单说明点位情况，我们将在评估后与您沟通合作方案。

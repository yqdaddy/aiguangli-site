A-2花城惠民·邻

便利店态 / 闪购态造型Convenience Store Mode / Flash Sale Mode

1.8 米进深（紧凑型）——为广州的窄街小巷而生

从城市街角现代微枢纽场景出发，整合报刊阅读与便利零售业态，设置双形态：便利店适配广州一刻钟便民生活圈，服务街坊高频刚需；闪购店依托夜经济，面向青年、游客打卡引流。

洽谈落地 A-2

省下 20 厘米，多出一条街

广州老城的街巷经不起浪费。A-2 把进深从 2.0 米收到 1.8 米，营业面保持 2400mm 宽的上翻窗不变——少占的是人行道，不省的是货架与灯光。巷口、骑楼下、绿带旁，从前放不下的点位，现在都装得下。

  • A-1 进深 2000mm ｜ A-2 进深 1800mm；两者总宽同为 4500mm、总高同为 2750mm

巷口的便利柜台

与 A-1 同源的营业配置：上翻窗升起、操作台翻下，双开口同时服务；报刊书架立在玻璃门内，当天的报纸永远是新鲜上架。老街坊买酱油的路，从此多一个选择。

  • 一刻钟便民生活圈高频刚需
  • 报刊阅读区与零售区并行动线

给电动车续命的街角充电站

A-2 背面没有冷藏柜，而是一整面“花城惠民24H换电柜”——格子灯亮起，外卖骑手、买菜归来的街坊，扫码换一块满电电池，三分钟继续赶路。这是 A-2 对“城市服务”四个字的回答：便利店里买得到水，亭背后换得到电。

  • 智能换电柜（工艺清单第 07 项）格口式设计
  • 24H 灯箱照明，夜间可视可寻
  • 服务人群延伸：外卖骑手、网约配送、街坊电动车

小一号的身材，同样的排场

  • 与 A-1 一致的红灰车身与三段式立面（石墨灰 BP-64311 / 红 PD-3442 / 浅灰 RAL7040）
  • “报刊亭”灯箱字 + 花城惠民招牌 + 迷你发光立体字（字体厚 2.5cm）夜间全亮
  • 背面 P2 LED 大屏 + 侧面民生海报灯箱，媒体位与 A-1 同规格

工艺清单（9 项）与结构细节

  • 上翻窗 H770mm
  • 气弹簧支撑杆
  • 可折叠服务操作台 H200mm

工艺清单

  1. 1.2mm 镀锌板，外表面采用户外氟碳喷漆
  2. 单面静止灯箱面板 6mm 钢化玻璃
  3. 迷你发光立体字，正面发光，字体厚 2.5cm
  4. 上翻窗 6mm 欧洲灰钢化玻璃 + 钣金边框
  5. 固定玻璃 8mm 透明钢化玻璃
  6. 内开门 8mm 透明钢化玻璃 + 铝型材边框
  7. 智能换电柜（A-1 为智能售卖柜）
  8. P2 LED 显示屏
  9. 水平调节脚座

空调表面需喷涂为深灰色（空调位预留）。

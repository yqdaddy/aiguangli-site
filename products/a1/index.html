A-1花城惠民·邻

便利店态 / 闪购态造型Convenience Store Mode / Flash Sale Mode

2.0 米进深（标准型）——一刻钟便民生活圈的街角主力店

从城市街角现代微枢纽场景出发，整合报刊阅读与便利零售业态，设置双形态：便利店适配广州一刻钟便民生活圈，服务街坊高频刚需；闪购店依托夜经济，面向青年、游客打卡引流。

洽谈落地 A-1

白天，它是街坊的便利柜台

上翻窗升起（H770mm），气弹簧支撑杆把窗稳稳托住，可折叠服务操作台（H200mm）翻下就是柜台。饮料、零食、应急日用从两侧货架与冷藏柜递出，玻璃门内的报刊书架整齐码着当天的报纸杂志——买瓶水的时间，顺手把今天的“精神食粮”也带回家。

  • 一刻钟便民生活圈里的高频刚需补给
  • 报刊阅读区独立成区（玻璃门防尘防潮，书架满架陈列）
  • 双冷藏陈列柜支持饮料乳品日配

夜晚，它是街角的灯

打烊不是结束。正面橱窗切换夜间陈列，背面“花城惠民24H零售店”灯箱亮起——两台冷藏柜在玻璃门后通宵待命，夜班归人、宵夜散步的青年与游客，都能在这盏灯下买到一口冰镇。

  • 背面 24H 零售店：冷藏陈列 + 通宵灯箱
  • 迷你发光立体字（正面发光、字体厚 2.5cm）保证夜间 200 米识别度
  • 闪购模式支持线上下单、街角自提

一眼认得出的街角新邻居

  • 红灰双色车身：石墨灰氟碳砂纹粉（BP-64311）打底，红色氟碳砂纹粉（PD-3442）勾勒主视面招牌带，浅灰氟碳砂纹粉（RAL7040）收边——“花城红”是这座亭的态度。
  • 三段式立面：顶部“花城惠民 Convenience Hub”招牌+迷你发光立体字；中部通长营业面（上翻窗+玻璃门报刊区，三视图分宽 2400mm）；底部灯箱广告带，轮播“便利店模式·一刻钟便民生活圈”形象画面。
  • 侧面民生海报位：“增进民生福祉 共创美好生活”主题画面位，政务宣传与公益内容的标准出口。
  • 全视角媒体位：背面 P2 LED 大屏，四向皆可为街头媒体。
